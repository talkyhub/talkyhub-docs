# Getting started

TalkyHub is a platform for talking to your customers: every request from email,
messengers and social networks is collected into one shared inbox, and your
support team answers them from a single workspace.

Getting up and running takes a few steps.

## 1. Create a workspace

Sign up at [talkyhub.ru](https://talkyhub.ru) and create a workspace. A workspace
is your team: it has its own channels, conversations, contacts and members.

## 2. Connect your first channel

A channel (inbox) is a source of requests. TalkyHub supports:

- **Email** — over IMAP (receiving) and SMTP (sending);
- **VK** — community messages;
- and more channels, added under **Channels**.

See [Channels](../channels/index.md) for connecting a mailbox and setting up
credentials.

## 3. Invite agents

Invite colleagues by email. Each member gets a role (administrator or agent) and
access to the workspace's conversations.

## 4. Handle requests

New emails and messages automatically turn into conversations. An agent picks up
a conversation, replies to the customer, applies labels and closes the request.
See [Working with conversations](../guides/conversations.md).
