# Что нового в приложении

Изменения в веб-приложении TalkyHub (app.talkyhub.ru) — от новых к старым.

## 1.2.0 — 25.10.2026

### Изменено

- **Превью виджета сайта — настоящий виджет.** В настройках канала сайта превью показывает тот же виджет,
  что увидят посетители, и сразу меняется при правке цветов, текстов, полей анкеты, ссылок и приветствия.
  Можно переключиться между видом на компьютере и на телефоне, открыть и закрыть чат, заполнить анкету.
- После создания канала сайта рядом с кодом для вставки видно, как виджет будет выглядеть на сайте.

## 1.1.0 — 25.10.2026

### Добавлено

- **Авито (бета)** — подключите аккаунт Авито по ключам API и отвечайте покупателям из TalkyHub. В диалоге
  видно объявление: фото, название, цена и статус («Продано», «Снято с продажи»), ссылки «Открыть на Авито» и
  «Чат в Авито», а «Другие диалоги» показывает всех, кто спрашивал про это объявление.
- В списке диалогов Авито под именем покупателя — миниатюра и название объявления.
- Ответы, отправленные из приложения Авито, тоже видны в диалоге с пометкой «Отвечено в приложении Авито».

### Изменено

- Вход и регистрация — один шаг: введите почту, и если аккаунта ещё нет, мы предложим создать пространство.
  Отдельной ссылки «Создать пространство» больше нет.

### Исправлено

- Выбор языка на странице входа больше не «уезжает» в сторону при открытии.
- На телефоне кнопка «Отправить» помещается в поле ответа.

## 1.0.0 — 18.10.2026

Первый версионированный выпуск приложения.

### Добавлено

- **Вход через Яндекс ID и VK ID** — под формой «Продолжить по почте». Если сервис не подтвердил почту,
  один раз подтвердите её кодом — дальше вход в одно касание.
- **Вход и безопасность** — новый раздел настроек: подключение и отключение Яндекс ID и VK ID, доверенные
  устройства для входа по код-паролю. Вход по коду на почту остаётся всегда.
- **Уведомления**: в браузере (даже когда вкладка закрыта), в Telegram и MAX. Для каждого события — отдельно
  «в приложении» и «push», тихие часы, кнопка «Отправить тест».
- **Новый диалог** — уведомление, когда клиент начинает диалог в доступном вам канале (по умолчанию выключено).
- **Приложение на телефоне и компьютере**: TalkyHub можно установить на экран «Домой» (iPhone, Android) или
  рабочий стол; число непрочитанных — на значке приложения и во вкладке.
- **Помощь** — кнопка «?» открывает справку по текущему экрану, «Что нового» и ссылки на документацию, не
  уходя из приложения.
- **Письма клиентов** показываются с форматированием и картинками из текста письма.
- **Новое письмо клиенту** — начать диалог по почте прямо из списка диалогов.
- **Объединение контактов** — слить дубликат в текущий контакт.
- **История правок сообщения** — по отметке «изменено».

### Изменено

- **Настройки** разделены на «Аккаунт» и «Пространство» с постоянным меню слева; на телефоне — список разделов.
  В настройки можно попасть по шестерёнке рядом с колокольчиком.
- На телефоне «Детали» диалога открываются отдельной вкладкой.

### Исправлено

- Выпадающие списки в окнах (например, «Новое поле») больше не прячутся под окном; работают стрелки и Esc.
- Сообщения об успешном сохранении теперь видны на всех страницах настроек.
- Понятное сообщение, если регистрация на сервере закрыта.
