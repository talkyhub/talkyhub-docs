# Как добавить канал

Канал подключается в интерфейсе за пару минут: вы выбираете тип канала,
заполняете короткую форму — и обращения из него начинают попадать в общий список
диалогов. Эта страница объясняет, как работает мастер добавления канала, что
понадобится для каждого типа и как настроить канал после подключения.

:::note Кто может подключать каналы
Добавлять и настраивать каналы могут только **администраторы** рабочего
пространства. Операторы видят список каналов, но форма подключения им недоступна.
:::

## Открыть мастер

1. Откройте **Настройки → Каналы**.
2. Нажмите **Добавить канал**.

Мастер состоит из трёх шагов: **Выберите канал → Настройте → Готово**. Слева вы
заполняете поля, справа — короткая инструкция именно по этому каналу.

## Шаг 1. Выберите канал

На плитке каждого канала указан его статус:

- **Доступен** — канал подключается прямо здесь, в мастере.
- **Через провайдера** — подключение идёт через внешнего партнёра (WhatsApp).

## Шаг 2. Заполните настройки

Что понадобится для каждого канала:

| Канал | Что нужно | Где взять |
| --- | --- | --- |
| **Telegram** | Токен бота | Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируйте токен |
| **MAX** | Токен бота | Кабинет [MAX для бизнеса](https://business.max.ru/self/chat-bots): Чат-боты → ваш бот → настройки |
| **ВКонтакте** | ID сообщества, ключ доступа, строка подтверждения | Управление сообществом → Настройки → Работа с API (Callback API) |
| **Электронная почта** | Данные IMAP и SMTP | У вашего почтового провайдера (см. [Каналы и почтовые ящики](./index.md)) |
| **Сайт (живой чат)** | Ничего заранее | Токен и код для вставки выдаются автоматически после создания |
| **WhatsApp** | Аккаунт у провайдера (360dialog / Twilio) | Через встроенную регистрацию провайдера |
| **API** | — (по желанию URL webhook) | Свой канал для сети, которую TalkyHub не поддерживает напрямую |

:::tip Название канала можно не заполнять
Поле **Название канала** необязательное — если оставить пустым, TalkyHub подставит
разумное имя (например, @username бота). Название видно только вашей команде и
меняется в любой момент.
:::

### Особенности отдельных каналов

- **ВКонтакте** требует «рукопожатия»: TalkyHub выдаёт URL и секрет, которые вы
  вставляете в экран Callback API сообщества и подтверждаете. Мастер показывает
  эти значения на шаге «Готово».
- **Сайт (живой чат)** после создания показывает **код для вставки** — однострочный
  `<script>`. Добавьте его на каждую страницу сайта прямо перед `</body>`.
- **WhatsApp** подключается только по официальному Cloud API через провайдера —
  неофициальных / QR-подключений нет.

## Шаг 3. Готово

Канал создан и уже принимает сообщения (для ВКонтакте — после подтверждения в
интерфейсе сообщества, для сайта — после вставки кода). Отсюда можно перейти к
диалогам или сразу добавить ещё один канал.

## Настройка канала после подключения

Откройте канал из списка **Настройки → Каналы**, чтобы задать:

- **Основные** — название, автоназначение новых диалогов, приватность (видимость
  только для участников), приветствие и сообщение при решении, участники канала.
- **Данные для входа** (почта) — параметры IMAP/SMTP; пароль оставьте пустым,
  чтобы сохранить прежний.
- **Виджет** (сайт) — код для вставки и обновление токена, акцентный цвет,
  положение и вид кнопки, имя в шапке, подпись о времени ответа, поля пречата и
  список разрешённых доменов.

## Лучшие практики

- **Понятные названия.** Называйте каналы по смыслу — «Поддержка», «Продажи»,
  «Сайт» — чтобы операторы сразу понимали источник обращения.
- **Один почтовый ящик — один канал.** Иначе два канала будут вычитывать одну
  папку и дублировать диалоги.
- **Проверьте канал сразу.** Напишите боту / на почту / в виджет тестовое
  сообщение и убедитесь, что диалог появился и ответ дошёл.
- **Приватные каналы для чувствительных очередей.** Включите приватность, чтобы
  диалоги видели только участники канала.
- **Распределяйте нагрузку.** Включите автоназначение и добавьте участников (или
  команду), чтобы новые диалоги расходились между операторами.
- **Приветствие и сообщение о решении** задают тон и экономят время — настройте их
  в разделе «Основные».
- **Для виджета сайта ограничьте домены.** Укажите разрешённые домены, чтобы код
  работал только на вашем сайте. Токен — публичный идентификатор; если код утёк,
  **обновите токен** и замените сниппет на сайте.
